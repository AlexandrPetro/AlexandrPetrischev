# Alexandr Petrischev — Portfolio

Минималистичное портфолио на Astro.

## Запуск локально

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

## Что нужно настроить

- Заменить временные ссылки на реальные контакты.
- Загрузить изображения в `public/`, чтобы не зависеть от временных Figma asset URL.
- Заполнить содержимое отдельных страниц проектов по макетам Figma.
